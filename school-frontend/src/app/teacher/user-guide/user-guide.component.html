Aether Portal Faculty Guide

Welcome to the Faculty dashboard. This guide explains how to use your teaching, attendance, and grading tools.

class 1. Managing Assigned Classes

View your classes and student lists:

  • Navigate to the **My Classes** panel.
  • Select any class from the dropdown to automatically retrieve the active student roster showing contact emails and parents.

fact_check 2. Submitting Daily Attendance

Mark daily class attendance registries:

  • Open the **Mark Attendance** panel.
  • Select the class and the target date (defaults to today).
  • Mark each student as **Present**, **Absent**, or **Leave**.
  • Click **Submit Attendance Sheet** to sync the records with the administration database.

assignment 3. Posting & Grading Assignments

Assign homework and review student submissions:

  • Go to **Assignments** and click **Create Assignment**. Specify details, due date, and optionally attach a PDF sheet.
  • Once students submit, click **Submissions** beside the assignment row to see files, dates, and grading options.
  • Click **Grade** to write remarks/scores feedback for each candidate.

emoji_events 4. Entering Student Marks

Input term grades for academic exams:

  • Open **Enter Marks** tab.
  • Choose the specific Exam term and Class-Subject combination.
  • Enter the marks obtained for each student (checked against max possible score).
  • Click **Save Student Marks** to publish.
