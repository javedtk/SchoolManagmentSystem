Aether Portal Administrator Guide

Welcome to the Super Admin control desk. This reference guide provides step-by-step guidance on standard tasks and features.

campaign 1. Managing Admission Desk

The **Admission Desk** is populated dynamically when visitors submit the admission registration form on the public portal.

  • Review all incoming applications under the **Admission Desk** tab.
  • To reject an inquiry, click **Reject**. This marks their record as rejected.
  • To approve/enroll, click **Admit Student**. Select their starting academic class and target section to automatically generate an active student record with default credentials.

badge 2. Faculty & Class Configurations

Set up teachers, subjects, and classes in logical order to avoid relational dependencies:

  1. **Add Teachers**: Create profiles for faculty members under **Manage Teachers**. Default system passwords will be generated automatically.
  2. **Create Classes**: Form groups (e.g. Grade 10-A) under **Manage Classes** and designate a Class Teacher.
  3. **Add Subjects**: Under **Manage Subjects**, associate courses (e.g., Mathematics, physics) with specific Class Rooms.

schedule 3. Establishing Class Timetables

Maintain precise weekly calendars to avoid period slot conflicts:

  • Select the target Class in the **Timetable Editor** page drop-down.
  • Click **Add Slot** to allocate a day, period slot number (1 to 8), times, subject, and assigned teacher.
  • The system will automatically validate the slot configuration. If conflict is found (e.g. teacher is already busy elsewhere), an error banner will block submission.

payments 4. Fee Collections & Billing

Manage invoicing structures and billing receipts:

  • Under **Fee Operations**, click **Define Billing Item** to setup fee schedules (e.g. Tuition Fee) for specific grade cohorts.
  • Students can view these invoices and submit mock payments from their dashboard.
  • Once paid, transactions appear under **Recent Fee Receipt logs** with options to download PDF copies of the receipt log.
